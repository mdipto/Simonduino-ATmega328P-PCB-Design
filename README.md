# Simonduino Color Match Game – ATmega328P PCB Design

## Project Overview

Simonduino Color Match Game is a course-guided electronics and PCB design project developed using Altium CircuitMaker.

The project explores the design of an ATmega328P-based interactive electronic game, integrating digital inputs, LED indicators, power supply circuitry, and communication interfaces.

The objective was to practice schematic capture, electronic component integration, PCB layout development, and 3D board visualization.

## Technologies and Tools

- **EDA Software:** Altium CircuitMaker 2.3.0
- **Microcontroller:** ATmega328P
- **Hardware Design:** Schematic capture, PCB layout and component placement
- **Interfaces:** GPIO, USB-to-serial circuitry, ISP programming interface
- **Components:** LEDs, push buttons, voltage regulation circuitry and supporting electronic components
- **Design Visualization:** 2D PCB layout and 3D component visualization

## Hardware Design

### 1. Schematic Design
Worked through the electronic schematic in Altium CircuitMaker, covering microcontroller connections, input switches, LED indicators, power supply circuitry and communication interfaces.

### 2. PCB Layout
Developed the circular PCB layout, including component placement, signal routing and board labeling.

### 3. Design Visualization
Inspected the PCB layout and component arrangement using CircuitMaker's visualization features.

## Testing and Verification

The learning process included circuit simulation and breadboard-based experimentation.

The PCB design has not been physically manufactured or assembled. Complete board-level functional verification and DRC clearance have not yet been documented.
